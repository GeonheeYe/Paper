iTransformer 정리

통신 KPI 예측과 이상 탐지 관점에서 본 Transformer 기반 다변량 시계열 예측 구조

최근 시계열 예측 분야에서 자주 언급되는 iTransformer를 정리해봤습니다.

저는 통신 KPI를 예측하고, 예측값과 실제값의 차이를 통해 이상 유무를 확인하는 관점에서 이 논문을 읽었습니다.

iTransformer는 단순히 새로운 예측 모델이라기보다, Transformer를 다변량 시계열에 어떻게 적용할 것인가에 대한 관점을 바꾼 중요한 구조입니다.

기존 Transformer 기반 시계열 모델들은 보통 각 시점을 token으로 보고 attention을 적용했습니다.

즉, 같은 timestamp에 있는 여러 변수들을 하나의 token 안에 묶어 처리하는 방식이 많았습니다.

하지만 다변량 시계열에서는 각 변수가 서로 다른 의미를 가집니다.

예를 들어 통신 KPI에서도 트래픽, 지연시간, 에러율, 세션 수, 처리량 같은 변수들은 같은 시간에 관측되더라도 서로 다른 패턴과 지연 관계를 가질 수 있습니다.

iTransformer는 이 구조를 뒤집습니다. 시간 포인트를 token으로 보는 대신, 각 변수의 전체 시간 흐름을 하나의 token으로 보고 attention을 변수 간 관계 학습에 사용합니다.

핵심은 다음과 같습니다.

  • 시간축 token 대신 변수 token 사용
  • attention으로 변수 간 상관관계 학습
  • feed-forward network로 각 변수의 시간 패턴 학습
  • 긴 lookback window를 더 효과적으로 활용
  • Transformer의 기본 구조는 유지하되, 입력 해석 방식을 전환

이 접근은 복잡한 모듈을 추가하는 대신, “무엇을 token으로 볼 것인가” 라는 기본 가정을 다시 본다는 점에서 의미가 큽니다.

iTransformer는 ICLR 2024 Spotlight로 선정되었고, 이후 NeuralForecast, GluonTS 같은 시계열 라이브러리에도 포함되었습니다.

또한 2025~2026년 후속 연구들에서도 baseline이나 개선 대상으로 계속 등장하고 있습니다.

그래서 iTransformer는 “시계열 예측의 유일한 표준”이라기보다는, Transformer 기반 다변량 시계열 예측에서 중요한 backbone이자 기준점이 된 모델로 보는 것이 적절합니다.

개인적으로 인상 깊었던 점은 모델을 더 복잡하게 만드는 것이 아니라, 입력 표현의 관점을 바꾸는 것만으로 성능과 해석 가능성을 개선했다는 점입니다.

통신 KPI 예측처럼 여러 지표가 서로 영향을 주고받는 환경에서는, 변수 간 관계를 어떻게 모델링할 것인지가 중요합니다.

그런 관점에서 iTransformer는 KPI 예측 기반 이상 탐지 문제를 고민할 때 참고할 만한 구조라고 생각합니다.
