iTransformer: 시간축을 뒤집어 보는 Transformer

지금 선택: iTransformer의 변수 토큰 관점 각 변수의 전체 lookback 구간을 하나의 토큰으로 보고, attention이 변수 간 상관을 학습합니다.

Figure 2: 무엇을 토큰으로 보나

동일한 입력 행렬을 두 관점으로 토큰화합니다.

기존 방식 토큰 수는 시간 길이 T입니다. 한 토큰 안에 여러 변수의 값이 함께 들어갑니다.
iTransformer 방식 토큰 수는 변수 개수 N입니다. 한 토큰 안에는 한 변수의 과거 궤적 전체가 들어갑니다.
발표 포인트 구조를 새로 만든 것이 아니라, Transformer block이 바라보는 축을 바꾼 것이 핵심입니다.

Self-Attention 시간 토큰끼리 모두 비교
6×6 = 36 scores
lookback이 길어지면 시간 토큰 수 T가 늘고, attention map은 T×T로 커집니다. 그래서 긴 과거 구간을 볼수록 score 수가 제곱으로 증가합니다.

iTransformer

변수 토큰 3개
Token 기온, 습도, CO₂
각 토큰은 전체 lookback
→
Embedding 3개 변수 토큰을
d_model 차원으로 변환
→
Self-Attention 변수 토큰끼리 모두 비교
3×3 = 9 scores
긴 lookback은 각 변수 토큰 내부에 들어갑니다. attention은 변수 토큰 N개끼리 비교하므로, 이 예시에서는 N×N = 3×3 score만 만듭니다.
